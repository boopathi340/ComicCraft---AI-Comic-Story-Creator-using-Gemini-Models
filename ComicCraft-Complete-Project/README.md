## Run Commands

### Backend
cd backend
venv\Scripts\activate
python -m uvicorn main:app --reload --port 8000

### Frontend
cd frontend
npm install
npm run dev

Frontend: http://localhost:5174
Backend: http://localhost:8000
Swagger: http://localhost:8000/docs
